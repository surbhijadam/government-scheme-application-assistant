# Government Scheme Application Assistant

A prototype web application that helps users discover government schemes
they may be eligible for and guides them through the application process.

> **Disclaimer:** This is a learning/prototype project. It is NOT an official
> government portal. Eligibility results are preliminary. Always verify scheme
> details through official government sources.

## Tech Stack
- Frontend: Streamlit
- Backend: Python, Flask (REST API)
- Database: MySQL
- AI (optional, later): Groq API

## Setup (Windows PowerShell)
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd backend
python run.py
```
